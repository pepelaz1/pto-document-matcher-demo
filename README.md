# Подбор документов ПТО — локальный прототип

Пример обработки PDF-спецификации и архива паспортов по ТЗ заказчика. В репозитории находятся **искусственные тестовые документы**, без клиентских данных.

## Запуск

Требуются Python 3.10+ и библиотеки из `requirements.txt`.

```powershell
python -m pip install -r requirements.txt
python app.py
```

Откройте `http://127.0.0.1:8501/` и нажмите «Подобрать паспорта». При первом запуске скрипт создаст тестовые PDF. Также можно загрузить свою PDF-спецификацию и указать локальную папку с паспортами. Формат таблиц произвольных проектных спецификаций пока не поддерживается: демонстрационный парсер ожидает строки с разделителем `|`.

## Уже работает

- Чтение текстовых PDF и кэширование извлечённого текста по MD5 в SQLite.
- Склейка перенесённой строки позиции; выделение примечаний.
- Разделение сборного PDF на документы с сохранением приложения в составе сертификата.
- Поиск кандидатов по словам, ГОСТ и диаметру. Балл — эвристика прототипа, **не измеренная точность и не оценка LLM**.
- Статусы «Найдено», «На проверку», «Не найдено», «Не требует паспорта»; проверка срока действия.
- Копирование исходных страниц в отдельный комплект, безопасные имена файлов, папка `_На_проверку`, Excel с реестром и дефицитом.

## Что потребуется для рабочей версии

На реальных документах заказчика нужно проверить структуру таблиц AutoCAD/Revit, качество сканов и точность разделения сборных PDF. Русский OCR предусмотрен как локальная точка подключения Tesseract, но требует установленного языка `rus`; адаптер PaddleOCR или Yandex Vision, LLM для спорных совпадений, ручную правку сопоставлений, контроль синхронизации облака 3 секунды и пакетный режим ещё предстоит реализовать. Обещание 90% возможно только после замера на тестовом пакете заказчика.

Исходные паспорта прототип не удаляет и не переносит. Выходные папки находятся в `output/`. Не загружайте в публичный репозиторий документы заказчика, `.env` и `cache.sqlite3`.
